# C 程式設計基礎（Introduction to Programming using C）

作者：林子祐（國立臺灣大學資訊工程學系）

一本給初學者的 C 語言教科書，21 章、578 頁，從基本程式架構、迴圈、陣列，到指標、字串、結構、遞迴、檔案處理、資料結構與前置處理器。每一章的範例程式都可以直接編譯執行，並附有常見錯誤與練習題。內容源自我在臺大擔任程式設計課程助教兩年的經驗，對應臺大資工系程式設計課程的題庫章節。

- 完整 PDF：[`output/book.pdf`](output/book.pdf)
- 原始碼：`src/`（XeLaTeX，`make book` 重新編譯）
- 網頁版：[annotated.codes/learn/c](https://annotated.codes/learn/c)（一節一頁，手機也好讀）
